# Security

Do not post credentials, personal tasks, calendars or location data in public issues. Reproduce with synthetic data and redact screenshots.

The application is a local-user tool. Loopback tokens defend against browser cross-site requests; they do not authenticate against other local programs or users. Weather shortcut names and saved launcher IDs restrict dispatch, but users remain responsible for the contents of shortcuts they install and the URLs they configure.

The current distribution is ad-hoc signed and not notarized by Apple. Verify the release source and SHA256 before allowing a downloaded copy in macOS privacy/security settings. Never disable Gatekeeper globally to run this project.
