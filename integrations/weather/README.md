# Apple 天气快捷指令

本项目通过系统快捷指令获取 Apple 天气，不读取天气 App 私有数据，也不从第三方天气网站抓取数据。本方案不需要配置 WeatherKit 开发者密钥；直接集成 WeatherKit 需要相应开发者服务配置，见 [Apple WeatherKit](https://developer.apple.com/weatherkit/)。

## 首次设置

1. 在实时页面点击“添加天气”，或双击同目录的 `Apple-Weather.shortcut`。
2. 在系统窗口检查内容并添加，系统默认名称 **Apple-Weather** 已自动兼容，也可命名为 **副屏天气**。
3. 在快捷指令 App 内运行一次，允许系统请求的位置权限。
4. 返回 Dashboard 点击天气刷新按钮。

随包的指令仅包含“获取当前天气”和输出天气文本两个动作，不含 shell、文件写入或第三方网络操作。`Apple-Weather.plist` 是可检查的源文件；`.shortcut` 是系统签名后的可导入文件。项目不会自动添加指令或自动点击授权。

如果系统不能导入，请手动新建同名指令，添加“获取当前天气”，位置设为当前位置，再添加“文本”，插入前一步的“天气状况”变量作为输出。可以先在快捷指令 App 内查看输出。Dashboard 支持带 °C／°F／℃／℉ 的天气文本，也支持你自己组装的 `{"temperature":21,"condition":"多云"}` JSON；JSON 温度约定为摄氏度。缺少温度时显示横线，不猜测数字。

## 多城市

1. 复制指令，命名为 `副屏天气 上海` 或 `副屏天气 北京`。
2. 在每个副本的“获取当前天气”动作中选择对应城市。
3. 页面设置 → Apple 天气位置 → 添加位置，填写显示名称及完整指令名 → 保存配置。
4. 在天气卡片下拉框切换位置。

最多6个位置。名称支持随包导入名“Apple-Weather”、“副屏天气”及带“副屏天气 ”前缀的城市名称。界面中的城市名称仅为标签，实际查询位置由快捷指令定义；不会自动读取天气 App 的收藏城市。

## 失败处理与数据范围

- “添加 Apple 天气”：指令不存在或名称不匹配。页面同时支持 Apple-Weather 和副屏天气；导入后手动刷新。
- “请先在快捷指令中运行天气”：先在系统 App 运行，处理位置／网络等权限提示。
- “暂时无法更新”：保留上次成功天气，明确标记上次数据。
- 温度为横线：输出没有可解析的温度。检查指令最后的文本动作是否包含天气变量。

自动刷新15分钟一次，手动刷新有5秒冷却；运行最长等待25秒。通过系统命令输出到临时目录，读取后删除；天气在服务内存中缓存，不写入日常配置。允许定位和天气服务网络请求由 macOS 管理。

当前随包验证涵盖指令签名、输出解析、调用参数及界面交互；本机已经实际验证快捷指令后台读取和页面真实天气显示。其他 Mac 首次仍需完成以上添加与授权。服务启动无输入命令时会发送输入结束，避免命令一直等待标准输入而超时；失败后会短间隔重试。命令行为参考 [Apple 快捷指令命令行说明](https://support.apple.com/guide/shortcuts-mac/run-shortcuts-from-the-command-line-apd455c82f02/mac)。
